# 映题 · 讲解匹配工作台

新卷录入后，教研可以查看每道题的推荐讲解，点字幕跳转，微调区间，确认后把视频挂到题上。本版选用高中物理，包含五部原创字幕板书视频、十个讲解单元和一套六题示例卷。原视频合计 4 分 39 秒，其中三部包含多道题。素材采用板书动画和字幕；设备有本地中文语音时，可在匹配播放器里打开朗读。

## 体验

打开随项目提供的独立 HTML，或直接用桌面浏览器打开本目录的 `dist/index.html`。页面自带一段 42 秒流程演示，按实例检索结果回放。当前示例无需安装服务或配置模型密钥。

1. 点第一题「平抛小球的落点」。点击播放会从原片 00:27 开始，在 00:56 停止。两条带时间的字幕分别对应题设和结论。第五题给出相同的高度和初速，改求着地速率，匹配到同一原片的 00:00–00:27。
2. 在第一题点击「调整起止」或「更换候选」。也可选完整微课《用等时间隔找平抛落点》。确认后，才会写入题目与所选视频、起止秒数的关联。撤下或拒绝时可以保存原因。
3. 切到第六题「断开电源后的电容器」。题库尚无对应讲解，可记录缺口。新建空白试卷后，录入自己的题干、答案、解析、知识点、年级和题型，系统会重新检索。
4. 「效果与成本」可修改计时假设、查看逐题预测、导出评测与审核反馈。浏览器本地分别保存各卷、各题和反馈事件。换浏览器或移动离线文件可能使用新的存储空间；反馈可导出 JSON 留存。

可复制的录入例题：

> 一木箱沿倾角 37° 的粗糙斜面向下滑动，动摩擦因数为 0.25。取 g = 10 m/s²，求木箱的加速度。

使用参考答案 4 m/s² 会推荐《斜面上的三种运动》的下滑片段 00:26–00:55。把摩擦因数改为 0.50、参考答案改为 2 m/s²，原讲解将因给定量不同退出可挂载候选。

## 效果与边界

| 输入与方法 | 有讲解时首选命中 | 无讲解时正确留空 |
| --- | ---: | ---: |
| 仅词面 BM25，干净字幕，26 道回归题 | 11 / 14 | 1 / 12 |
| 本版核对题设与所求量，同 26 题 | 14 / 14 | 12 / 12 |
| 另 12 道同源改写题，修订后回归 | 6 / 6 | 6 / 6 |
| 去掉部分换题提示、全部板书，扰动时间戳，同 26 题 | 13 / 14 | 12 / 12 |
| 在上一行基础上再删除约四分之一发言，同 26 题 | 6 / 14 | 12 / 12 |

命中要求视频正确，预测区间与任一可用答案区间的时间交并比至少为 0.5。基线和本版使用相同的候选片段；基线拒推阈值根据另 11 道开发题的正负样本平衡得分选择。本版通过条件冲突、证据完整性和排序分决定是否展示可挂载推荐。排序分是规则分，不是正确率。

干净回归集里，11 个命中的长视频查询起点、终点平均绝对误差均为 0 秒。脚本转场和编辑切点都很规整，且部分题重复查询同一个片段。开发中曾发生碰撞对象质量对调、电压与电压比混淆、水平抛出改写漏召回等错误，已用于修订。因此这些数字描述这组自建回归样例，真实教研准确率与片段边界误差仍待盲评。弱字幕实验提供单独的敏感性测试，无真实 ASR/OCR 质量保证。

## 方案依据

- **切到题目级片段。** 视频只提供整部媒体、按时间排列的原话及屏幕板书。建索引时从转题语、前题收束和新数据/所求量出现识别边界，以相邻字幕间隔取中点。段落切分的参考来自主题分段研究，本版使用适应讲题语言的边界规则。[TextTiling，Hearst](https://aclanthology.org/J97-1003/)
- **检索后核对。** 中文双字词、字母和数值参与 BM25 词面排序。本版进一步核对物理模型、所求量、条件、对象与量值、单位换算、解析线索及参考答案。模型/单位匹配表集中在 `dist/matcher.js`。返回命中条件、冲突、原字幕和起止时间，未提供题目 ID 到视频 ID 的查询表。[BM25 计算参考](https://www.sqlite.org/fts5.html#the_bm25_function)
- **审核产生可用数据。** 每次确认、替换、改边界、撤下、拒绝或记录缺口，保存题目、原推荐、实际选段、前后关联、规则版本、原因与审核页面停留时间。停留时间含中途离开，不能直接充当教研操作用时。
- **真实视频接入候选。** 可复用 `createIndex(courses)` 与 `search(index, question)`。课程输入包含视频地址、时长、年级、题型和带时间戳的字幕，可附板书。下阶段可用已有 SRT/VTT 或 ASR 生成字幕，抽关键帧做板书 OCR，对比词面与中文向量召回，仅对小批候选重排。当前版本未使用外部大模型、向量模型、音轨转写或画面 OCR。[Whisper](https://github.com/openai/whisper) · [BGE-M3](https://huggingface.co/BAAI/bge-m3)

## 业务价值与成本

浏览器本地匹配，每题外部模型调用 0 次、API 费用 ¥0。首次索引和单题 P50、P95 用相同检索实现测量，计时不含读视频、首屏加载和人工审核。实测明细见 `research/results.json`。素材制作、设备、托管、真实课堂转写与人审需另计。

示例按 100 题、纯人工找片 5 分钟/题、复用率 60%、复用时审核 1 分钟/题、未命中时预筛 0.5 分钟/题计算。纯人工需要 500 分钟。辅助流程需要 60 × 1 + 40 × (0.5 + 5) = 280 分钟，预计节约 220 分钟，约 3.67 小时。此处是可替换参数的测算；尚无教研员真实计时。

## 小规模试点

| 阶段 | 可交付的结果 | 决策依据 |
| --- | --- | --- |
| 建立盲标集 | 选两套新卷、20 部已有多题讲解，邀请两位教研独立标注可挂载候选、完整讲解边界和缺口，分歧由第三次复核解决 | 按原课与题族隔离开发和评测，单列同题、可用变式、相似错题、缺讲解 |
| 接入真课 | 用真实字幕和板书建索引，对齐片段，比较当前规则、向量召回和重排 | 按题统计推荐精确率、覆盖率、Top-3、错挂原因；按片段统计时间交并比、起止误差 |
| 验证人效 | 两组教研交叉处理不同但同难度的新卷，一次人工查找、一次辅助审核 | 统计每题净耗时、每道成功挂载总成本、拒绝/替换率，连同失败样例决定是否扩大素材库 |

## 工程与复现

| 位置 | 内容 |
| --- | --- |
| `dist/` | 可直接打开的静态应用、真实 WebM 视频和预览帧 |
| `src/lessons.py`、`src/build_media.py` | 原创板书脚本及渲染器。编辑切点作为评测标注另存 |
| `dist/matcher.js`、`dist/app.js` | 独立检索接口和教研审核工作流 |
| `research/cases.json`、`research/paraphrases.json` | 开发、回归与改写题及可接受的讲解标签 |
| `research/editorial.json`、`research/results.json` | 独立于检索的剪辑金标，及逐题预测、耗时与压力测试 |
| `src/evaluate.cjs`、`src/check_ui.mjs` | 重跑检索对照、DOM 层审核流程回归 |
| `src/build_walkthrough.py`、`src/build_release.py` | 生成 42 秒流程演示和单文件离线交付物 |

使用现成素材，重新评测只需要 Node.js 18 或更新版。在项目目录运行：

```sh
node src/evaluate.cjs
```

重新生成板书与流程视频需要 Python 3.9+、Pillow 和可用的中文字体。Linux 或 Windows 可以设置 `CJK_FONT`；需要指定 Node 可执行文件时设置 `NODE_BIN`。导出的交付 HTML 无第三方网络依赖。可运行：

```sh
python3 src/build_media.py
node src/evaluate.cjs
python3 src/build_walkthrough.py
python3 src/build_release.py
```

开发用 DOM 回归可安装可选依赖 `linkedom`，然后运行 `node src/check_ui.mjs`。此检查模拟媒体状态；实际视频解码与时间轴另行验证。
